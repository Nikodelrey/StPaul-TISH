TISH Single-Family Filler

My defaults

Set up the answers you give on most houses, then save them as defaults. Every new inspection starts from them. The address and date are not included.

One-time setup: the TISH Fill bookmark

  1. Copy the code below.
  2. In Safari, bookmark any page, then edit that bookmark. Name it TISH Fill and replace its address with the code.
  3. On the St. Paul portal's More Info step, tap the bookmark, paste your fill code into the box that pops up, and tap OK.

Backup: the TISH Grab bookmark

  1. Make a second bookmark the same way, named TISH Grab, using the code below.
  2. Open a job on the St. Paul portal to its More Info step and tap TISH Grab.
  3. Type the address, tap Save to Files, and pick a folder. Open from Files in this filler loads the copy.
